# 原生天气与城市设置

日期：2026-09-27。独立 `native/` 工作区，未替换安装版、未生成安装包。

## 本阶段内容

- 天气页显示真实城市、当前温度、天气及未来三天预报，不再使用演示天气。
- 原生 Win32 城市设置：中文输入、搜索、结果选择、保存、取消，标准控件支持 Tab/Enter/Escape。工具栏仍使用紧凑图标，无功能名称。
- 原生配置独立存放；缺少原生配置时只读旧版城市。测试显式指定隔离文件。保存使用临时文件和原子替换。
- 一个天气工作线程、一个待执行任务和一个结果槽；新请求替换旧请求。隐藏、关闭或离页使旧结果失效。
- 天气缓存最多 4 城市，30 分钟有效，失败后 60 秒再试；失败仅保留同一城市缓存，不挪用别城数据。页面分钟级检查，缓存有效时不重复联网。
- 城市结果按行政中心和人口排序，合并中文原名及“市”后缀结果；避免同名国外小聚落先于国内城市。

## 网络与资源

使用 Windows WinHTTP，沿用当前用户系统代理，HTTPS 证书验证保持开启；不加载 WebView2。只允许 Open-Meteo 两个固定主机，禁用重定向，响应上限 256 KiB。接口依据 [天气文档](https://open-meteo.com/en/docs) 和 [地理编码文档](https://open-meteo.com/en/docs/geocoding-api)。

请求在工作线程执行，任务预算 20 秒，各网络阶段设置 2/4/4/8 秒超时。在阶段之间及读取块之间检查取消，过期结果立即丢弃；同步 WinHTTP 调用不能在当前阶段内立即中断，关窗或退出时线程清理可能等待该阶段返回，尚需改进为异步取消。系统代理自动发现和网络栈的具体超时行为仍需更多环境验证。

关闭城市窗口销毁 HWND、标准控件、字体和城市列表。隐藏主窗口释放当前页面和图形设备，保留有界天气缓存；已有线程在无任务时等待，不轮询。页面时间标签来自气象服务的城市当地观测时间，不是机器本地请求时间。

## 本机测试方式

按用户要求，窗口固定在左侧副屏 `\\.\DISPLAY2`，工作区 `(-1920,0)-(0,1032)`；右侧主屏不用于 UI 测试。窗口显示前定位，设置跟随主窗口，基准模式不抢焦点。自动化仅向自有 HWND 发送消息，不移动鼠标或发送系统键盘输入。

脚本验证中文搜索、隔离保存、三天预报、缓存复用、隐藏停止绘制及请求、12 次设置窗口销毁/重建，并记录全部窗口边界。截图仅本地检查，避免提交截图背景中的桌面内容。

## 验证结果

`cargo fmt --check`、严格 Clippy、Release 构建通过；35 项单元测试通过，1 项网易云联网测试默认忽略。本阶段天气测试实际联网通过，截图检查未见天气内容裁切。

预热 5 秒后，可见和隐藏各采样 60 秒。CPU 按整机逻辑处理器归一化：

| 场景 | 平均 CPU | 平均私有内存 | 平均工作集 |
|---|---:|---:|---:|
| 天气可见、数据已加载 | 0.0087% | 58.45 MiB | 52.89 MiB |
| 隐藏、图形资源释放 | 0.0000% | 12.68 MiB | 31.98 MiB |

0.0000% 表示采样期间未计到 CPU 时间增量，不代表所有环境永久为零。采样不包含正在联网的开销，也未启用真实音乐采集。

隐藏 60 秒新增帧数为 0；总请求始终为 3 次（两次城市查询、一次预报）。12 次页面及设置窗口循环后，每次结束私有内存均为 59.57 MiB、句柄均为 576，未见随循环增长。进程无子进程，未启动 WebView2。

窗口边界记录确认全在左侧工作区内：主窗口 `(-1200,0)-(-720,480)`，城市窗口 `(-1238,322)-(-682,709)`。本阶段没有修改用户当前显示器布局。

原始数据：[live-weather-results.json](performance/native-weather/live-weather-results.json)。构建 SHA256：`9508bd9dde7a8eeb844e01cc82a71aaa5d3292fc63f55dfbefcb6afec2672217`。
