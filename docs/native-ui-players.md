# 原生播放器选择与优先顺序

2026-09-27，接入 C02/S03 的会话列表、选择与排序。

## 实现

- F8 打开原生设置，“播放器…”打开原生选择窗口。支持允许全部、单项启用、上下调整顺序、刷新、保存和取消；标准控件提供键盘焦点及无障碍名称。
- 后台只读枚举 GSMTC 会话，按应用 ID 合并。列表保留保存过但当前未运行的项目，刷新不删除其顺序和勾选；识别常见播放器名称，并显示精确 ID 以区分同名来源。
- 新枚举最多读取 64 个会话；合并后的编辑列表最多 256 项，超限明确报错并禁止保存，不截断原配置。
- `selectedPlayerIds: null` 表示允许全部；空数组表示全部禁用。沿用既有 `playerOrderIds` 优先算法，同一 ID 的多会话优先正在播放或更新时间较新的会话。
- 配置后台保存成功后传入真实媒体服务，启动时也读取同样配置。改变选择会清除旧快照和控制目标；采集过程中发生修订时不发布旧选择的结果。
- 列表只在打开或手动刷新时查询，不新增常驻轮询。完成后释放该次查询的管理器；关闭窗口取消请求并释放控件、字体、列表及查询线程。关闭设置父窗口也会关闭播放器窗口。
- 所有修改仅写独立原生配置，不改安装版配置，不注册或启动播放器。

## 验证

- 格式检查、严格 Clippy、Release 构建通过；52 项单元测试通过，1 项既有联网测试默认忽略。
- 单元测试覆盖全部允许/全部禁用语义、保存保真、优先算法、离线项目合并和超限保护。
- 左侧副屏真实发现 1 个网易云会话，加 2 个未运行测试项目；单项勾选、调整顺序、允许全部、全部禁用、重启恢复通过。允许全部时成功读取真实会话，全部禁用后会话编号恢复为 0。
- 整个测试只读媒体状态，不发送播放、暂停、切歌、音量或设备切换命令。
- 12 次播放器窗口开关：句柄数始终为 556；私有内存首轮 57.50 MiB、末轮 57.63 MiB。本轮只是生命周期检查，不替代长时间性能基准。
- 刷新后立即关闭父窗口通过；工具开关、动画、六个时区及重启回归通过。全部窗口边界在左侧 DISPLAY2，不抢焦点。
- 已检查播放器窗口截图；截图含真实应用 ID 与桌面边缘，仅保留本地，不提交。

证据：[播放器交互与资源](performance/native-players/native-players-results.json)、[设置回归](performance/native-players/native-settings-results.json)。

## 限制及后续

当前验证了网易云一个真实会话，多应用同时存在、播放器启动/退出与不同系统版本仍需扩展矩阵。列表查询与主媒体采集可能短暂各持有一个只读管理器，未实现未来完整多窗口的共享服务消费者管理。异步请求等待可取消，Windows 同步枚举调用若异常阻塞仍会影响查询线程退出时长。窗口尚未补齐跨 DPI 动态重排与极小工作区滚动。启动播放器入口、完整 Studio、预览和辅助播放窗口继续迁移。
