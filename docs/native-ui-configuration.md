# 原生配置兼容与保存

日期：2026-09-27。对应 C01/C02、S09 的配置基础部分；完整 Studio 和所有设置的运行时应用尚未完成。

## 改动

- `isle-core` 增加与窗口、Tauri 无关的完整 `AppPreferences` 模型；测试逐字段比较旧模型默认值，防止默认配置漂移。
- 保存时保留整个 JSON 对象，包括原生界面尚未使用的外观、播放器顺序、工具开关及未知嵌套字段；仅修改本次编辑的城市字段。缺失项补默认值，已有未知枚举字符串保留，不擅自转换。
- 兼容 `edgeShoulderRadius`、`autoHide`；新字段存在时优先使用新字段。缺少悬浮窗独立置顶字段时继承旧置顶值。旧别名仍留在文件中。
- 默认只读旧版路径，原生配置写入独立目录。首次从旧版迁移并明确保存时，先将原始字节备份为 `settings.legacy-backup.json`，再写原生文件；不会修改旧配置或注册表。
- 后续成功保存前，用 `settings.previous.json` 保留上一版原始内容。两个备份文件固定，不随正常保存次数增加。
- 文件最多 1 MiB。损坏 JSON、非对象根节点、已知字段类型错误、数值溢出或无效城市会使配置只读失败，不自动回落旧配置覆盖原文件。设置窗口显示原因。
- 写入临时文件并同步，再原子替换目标；本次保存失败会清理自身临时文件。进程崩溃留下的临时文件不会被当成配置读取，也不会被自动批量删除。
- 原生实例以独占文件句柄协调保存，崩溃后操作系统释放句柄；写入前核对启动时原始字节，发现外部修改就拒绝覆盖。外部程序不遵守此锁时，检查与替换之间仍存在并发写入窗口。
- 保存在专用后台线程完成；最多一项保存、一个结果。保存中禁用输入与重复提交；允许关闭窗口，已接受的保存仍完成。结果到达隐藏界面时不重新挂载页面。

## 验证

- 格式、严格 Clippy、Release 构建通过。
- 45 项单元测试通过，1 项网易云联网测试按原约定忽略。
- 覆盖旧配置迁移、原文件字节不变、备份与重启、未知字段/嵌套字段保留、别名优先级、损坏保护、实例冲突、Windows 文件占用导致替换失败、临时文件清理和失败后重试。
- 在左侧副屏执行城市搜索、后台保存、重启恢复、12 次设置窗口销毁/重建；未抢焦点。测试配置包含虚构播放器顺序、`autoStart: true` 及未知字段，验证字段保留；没有执行自启动操作。
- 另以损坏、字段类型错误、超过 1 MiB、有效未知字段四组隔离配置启动原生程序，全部原始字节保持不变；无天气请求。

证据：[保存与重启](performance/native-configuration/live-weather-quick.json)、[启动保护](performance/native-configuration/configuration-fault-results.json)。本轮 5 秒快速采样只用于生命周期回归，不用来替代上一阶段 60 秒数据或宣称新的性能收益。
