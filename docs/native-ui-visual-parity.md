# 原生 UI 逐页复刻记录

更新：2026-09-28。目标是旧版现有界面的 1:1 复刻；以下是阶段记录，不代表全量验收。

## 本轮实现

- 从已安装的 lucide-svelte 提取 20 个原版 SVG，Direct2D 直接绘制；随构建附带原许可。生成脚本为 `scripts/sync-native-icons.mjs`。
- 对齐工具栏、详情标题、返回按钮、内容边距、音量与倒计时刻度、固定宽度数字、时间日期、天气当前值及三日预报的位置和字体。
- 倒计时恢复 20 分钟默认值、1–1440 分钟刻度、启动/暂停/继续/取消及完成卡片；状态独立于可见页面。收起态显示剩余时间和进度。
- 设备菜单叠加在现有尺寸内，展开箭头翻转，支持按像素滚动及边缘部分行；绘制裁剪与点击区域使用同一视口。
- 修正横向滚轮方向，工具栏支持 Home/End。数字读数使用原版固定数字槽尺寸，尚未迁移滚动数字动画。
- 新增隔离的 `--test-fixture` 数据与 `--test-taskbar` 检查入口。测试数据不启动真实音量、媒体、频谱或天气服务；设备选择只改测试状态。
- 构建时跳过内容未变的字体复制，避免正在运行的测试实例占用字体文件导致重复构建失败。

## 参考与验证方法

`ui-tests/native-parity.pw.ts` 渲染生产 Svelte 组件、MiSans 和固定数据，记录 8 个状态截图及真实 DOM 布局。输出位于被 Git 忽略的 `artifacts/parity/`。这项测试生成旧版参考，不是自动断言新旧像素一致。

原生 Release 测试使用独立配置，固定左侧 `DISPLAY2`。本轮实际点击验证音量拖动、设备选择、工具栏滚动、时间/天气切换，以及倒计时启动、暂停、空白收起、自动完成与关闭提示返回音乐页。没有修改真实系统音量或输出设备。桌面截图包含用户桌面内容，不提交。

检查：Rust 58 项通过，1 项联网封面测试按默认忽略；Clippy `-D warnings` 通过；Svelte 检查 0 错误、0 警告；参考截图测试通过；原生 Release 构建通过。本轮未重新执行旧 Python 桌面自动化脚本，也未重新测量性能。

## 补充：收起封面与弹簧（2026-09-28）

- 修复收起态误释放封面并绘制时钟图标：现在使用原版 20×20 圆形封面，按四向贴边的凹肩留白布局，无封面时显示原版音乐图标。
- 封面播放旋转周期 8 秒；暂停、悬停、减少动画或离开收起音乐状态时停转。展开/收起复用纹理，离开可见音乐内容后释放纹理和画刷，换曲重置角度。
- 将原生另一组物理系数替换为旧版 Svelte stiffness=.18、damping=.8 的 60Hz 递推轨迹，并用矩阵分数次幂支持不同帧间隔。保留中断时速度、精确收敛与减少动画直接到达目标。
- 修复空闲时间错误计入新动画第一帧导致起步跳变；内容绘制按同一动态轮廓裁剪，避免形变中露出页面直角。
- 新增原版轨迹对照、封面旋转生命周期、浮动/四向贴边封面几何测试。Rust 61 项通过，1 项联网测试默认忽略；Clippy 严格检查及 Release 构建通过。副屏实机确认真实媒体收起封面与展开页封面一致。
- 这次没有验收所有页面进出、滚动数字和按钮按压动画；这些仍在上表的剩余项中。

## 补充：数字滚动与详情页入场（2026-09-28）

- 音量、倒计时、时钟及收起倒计时读数接入逐位数字滚动：280ms、`cubic-bezier(.22,1,.36,1)`、最短十进制路径，包含 9↔0；连续变更从当前画面位置继续，长期运行重置位移基准以免浮点数累积。
- 详情内容使用旧版 180ms `ease` 淡入与 4px 向上位移，在形状允许显示内容时才开始。减少动画直接显示最终内容。
- 只保存当前页的数字状态；切页、收起或没有数字内容时清理，不保留旧页截图或离屏页面。数字/入场完成后退出连续刷新。
- Rust 63 项通过，1 项默认忽略；Clippy 严格检查和 Release 构建通过。数字单元测试覆盖跨 9/0、中途反向、精确结束与减少动画。
- 此处补齐的是详情入场；旧页退出、按钮按压/悬停、刻度移动等动画仍需继续对齐，全界面 1:1 尚未完成。

## 补充：旧页退出与刻度滑动（2026-09-28）

## Studio 基础层（2026-09-28）

- 原生设置窗开始沿用旧版深色基本色（背景 `#0e0f12`、控件表面 `#22252a`、正文 `#f5f6f7`），通过进程私有字体加载使用项目已附带的 MiSans，不安装系统字体。
- 窗口定位到灵动岛所在显示器的工作区；副屏实测位置、文本/编辑框/列表对比度。关闭时释放新增 GDI 画刷和私有字体资源。
- 现有 Win32 原生控件仍是临时布局。旧版的双栏分组、白色实时预览、设置卡片、状态、悬浮播放器和独立倒计时窗口尚未迁移，**Studio 尚未达到 1:1**。没有执行关机。
- `ui-tests/native-studio-reference.pw.ts` 在 1440×960 浏览器视口用生产 Studio 组件采集完整截图及布局，输出到被忽略的 `artifacts/parity/`。实测旧版内容高约 2528px，预览舞台约 523×468px，右侧设置栏约 693px 宽。这说明现有 540×930px 设置窗无法通过调色完成复刻，下一步须实现可滚动双栏布局和共享岛预览。
- `ui-tests/native-auxiliary-reference.pw.ts` 又采集独立倒计时初始态与悬浮播放器空闲态。倒计时初始壳体约 349×349px。浏览器演示下的悬浮播放器没有真实媒体、封面及交互状态，**不能当作播放态 1:1 参考**；仍需在左侧副屏采样旧版真实窗口的播放、暂停、封面、悬停、缩放和圆形模式。
- 主岛顶部功能图标按下缩至 95%，音乐控制图形按下缩至 94%，与旧版 CSS 值一致；悬停和焦点背景沿用之前的同源样式。尚未覆盖所有详情页按钮，不能算完整按钮状态验收。

## 网易云进度回退（2026-09-28）

- 网易云媒体会话持续返回空 SMTC 时间线时，从首次观察到当前曲目起使用本地单调时钟估算播放位置；暂停冻结，恢复后续计，收到有效位置后校准，换曲重新起算。歌曲总时长继续从严格匹配的元数据补全。总时长尚不可用时仍显示未知时间，避免显示错误的剩余秒数。
- 左侧 `DISPLAY2` 的真实媒体 8 秒诊断：媒体会话正常、歌曲总时长 275504ms、估算位置 7648ms，进度可绘制；Rust 66 项通过、1 项联网测试默认忽略，Clippy 与 Release 构建通过。
- 播放器完全不提供位置时，这条进度是从原生程序首次看到歌曲起计算的估值；如果歌曲在程序启动前已经播放一段时间，开始时会偏低。完整 Studio、悬浮播放器和独立倒计时的原生复刻仍在进行。

- 预览使用主岛的 Direct2D/DirectComposition 渲染器和 `Model` 几何。形状滑块、贴边样式与方向、功能栏开关会更新预览；示例曲目信息仅用于预览，关闭 Studio 时释放第二个渲染器及窗口资源。副屏截图确认白色舞台和主岛同源轮廓、功能栏、音乐与进度绘制。
- 当前右侧仍是系统原生按钮、组合框与刻度控件，缺少旧版设置卡片细节、全部设置项、状态切换和实时媒体封面；Studio 仍未达到 1:1。Rust 67 项通过、1 项联网测试默认忽略，Clippy 与 Release 构建通过。本轮没有重新做 CPU/内存对比。
- 补入旧版的收起、悬停、展开、隐藏预览状态。前 3 项复用同一个原生 `Model` 及渲染器切换形状；隐藏状态立即释放预览渲染器，重新选择可见状态时才重建。副屏截图确认展开与悬停预览，窗口级自动化尚未覆盖隐藏态资源计数。
- 四个预览状态入口改为 Win32 自绘分段按钮：深色背景、白色选中块、圆角、按压与键盘焦点。副屏 Release 截图确认按钮四角不再露出系统按钮的白底；其余设置控件仍须按旧版卡片设计继续迁移。
- 右栏静态文字和复选项背景统一为卡片表面色，消除系统控件周围的黑色条带；外观、功能与动画、天气改成独立圆角卡片，随右栏一起滚动，左侧预览舞台保持固定。副屏 Release 截图复核了卡片间距及上半部分控件。原生下拉框、滑块、按钮和复选项仍与旧版样式有明显差距。

## 原生悬浮播放器起步（2026-09-29）

- 顶部工具栏的悬浮播放器入口不再显示原型提示，而是打开独立 Win32 无边框圆角窗口。空闲态显示居中音符；播放态共享主岛的封面 `Arc`，显示曲名、歌手和按截止时间推进的进度，悬停时显示上首、播放/暂停、下首及关闭控件。媒体操作发送到同一 GSMTC 会话，关闭时释放窗口和封面引用。
- 悬浮窗在副屏打开，按 Escape 关闭后主岛仍运行。副屏 Release 截图核对了空闲和固定封面场景。首次空歌手绘制崩溃已修复；进度计时器只在播放且总时长已知时运行。原配置的悬浮窗置顶选项现可从原生设置读取和切换。
- 这仍是**原生播放窗的第一版**：真实封面播放态尚需与旧版实机并排比对；窗口位置保存、锁定、圆形封面、MV、封面效果、进度拖动、完整键盘/UIA 及进出动画均未完成。不可将当前播放窗标为 1:1。

## 独立倒计时窗口起步（2026-09-29）

- 加入不依赖 WebView2 的独立 Win32 倒计时窗口，F9 打开；5/10/25/60 分钟预设与 1–1440 分钟自定义输入共用主岛的倒计时状态。开始、暂停、恢复、重置、完成与关闭操作不会另起一个计时器。
- 使用固定 `DISPLAY2` 的 Release 测试：25 分钟预设启动后秒数下降，暂停后停住；95 分钟自定义值正常显示并启动；2 秒完成场景显示 `0:00:00` 与完成状态，重置回到选择页。首次载入 MiSans 由进程统一注册，Studio 不再重复注册同一字体。
- 当前窗口保留黑色圆角、白色大数字、蓝色确认键和四个预设卡片；仍缺少旧版的数字滚动、收起态、位置锁定、置顶/最小化控件、窗口位置保存、完整焦点顺序与逐像素对比。该窗口**尚未达到 1:1**。
- 补验完成→重置→重新开始：完成时隐藏输入框，重置后自定义输入与预览值一致；关闭独立窗口后，主岛倒计时页仍显示进行中的剩余时间。首次创建原生编辑框时的空值通知不再使原本有效的自定义时长失效。
