# 原生工具栏与动画设置

2026-09-27，原生设置开始接入运行时。工具、动画、时区和首批外观位置选项已有原生入口；完整 Studio 布局及预览仍未完成。

## 本阶段

- 城市设置窗口扩展为原生设置，增加功能栏总开关、七个工具开关、启用动画、减少动画和“灵动岛始终置顶”。使用 Win32 标准复选框，保留键盘操作和无障碍名称。置顶开关只控制主灵动岛；悬浮播放器仍使用独立偏好。
- “应用设置”通过现有后台保存服务写入独立原生配置，成功后立即应用；保存中禁止重复提交，失败保留草稿与原配置。关闭窗口会丢弃未应用修改。
- 工具按固定身份排序，过滤关闭项后紧密排列；一项时居中，最多同屏五项。绘制、命中、键盘焦点、滚动和几何使用相同可见项集合。
- 关闭全部工具不留下顶部空白。F8 可从主岛打开设置，避免设置按钮被关闭后没有恢复入口；F8 为窗口内按键，不注册系统全局快捷键。
- 动画关闭或减少动画时，形状直接到达目标；再次启用后恢复原弹簧。系统动画偏好和本次运行测试覆盖继续参与计算。`--reduced-motion` 运行期间保持减少动画。
- 保存工具开关不更改城市，不停止音乐或倒计时，不改变屏幕锚点。启动时读取已保存工具与动画设置；其他尚未迁移字段继续原样保存。
- 后续增加了悬浮/贴边、贴边方向和沿边位置设置；细节与验证见[原生外观与贴边位置](native-ui-appearance-position.md)。
- 原生外观设置现在包含专辑主色和自定义 `#RRGGBB` 背景色，颜色随封面缓存计算并在保存后即时应用；详情与测试边界见[原生背景色](native-ui-color.md)。

## 验证

- 原生置顶开关与其余设置共用保存流程；副屏回归验证了即时取消/恢复、`alwaysOnTop` 和 `floatingWindowAlwaysOnTop` 分离保存，以及重启还原。
- 工具栏首次接入时，格式检查、严格 Clippy、Release 构建通过；47 项单元测试通过，1 项既有网易云联网测试默认忽略。
- 新增核心测试：工具开关保真保存、不修改城市；稀疏工具保持身份、间距和导航，关闭全部项清除失效焦点及滚动。
- 本轮置顶设置完整工作区回归：55 项测试通过，1 项网易云联网测试默认忽略；严格 Clippy 与 Release 构建通过。
- 副屏实测：选择倒计时/时间/天气，关闭设置按钮后 F8 重开，关闭总开关后恢复，未应用草稿取消，动画开关及减少动画保存，重启恢复。
- 窗口边界检查覆盖四个方向和设置窗口，全部留在左侧 DISPLAY2；测试不发送系统键盘/鼠标输入，不抢焦点。
- 天气回归通过中文搜索、城市保存、字段保留、备份、重启和 12 次窗口开关。
- 已检查设置窗口截图，文字与控件未裁切。截图包含桌面边缘，仅保留本地，不提交。

证据：[设置交互](performance/native-settings/native-settings-results.json)、[天气回归](performance/native-settings/live-weather-quick.json)。快速采样不用于宣称新的性能收益。

## 后续

原生设置仍未覆盖全部 Studio 控件：频谱样式、颜色、显示器选择、语言、字体和实时预览仍待迁移。当前设置窗口使用系统原生控件，尚未完成 Studio 视觉复刻、不同 DPI 间拖动后的重排和小工作区滚动适配。功能栏中的悬浮播放器仍保留原型说明，尚未迁移其窗口。
